# CC0-Naturobjekte als Rohstoff — drei Bibliotheken, eine Probe (Studio#417)

Frage des Menschen (cnc#96): lizenzfreie Naturobjekte fremder Bibliotheken
nutzen statt alles selbst bauen? Diese Probe zeigt, wie fremdes CC0-Material in
der Engine aussieht — **roh** und **mit unserer Palette drueber**.

Alle Bilder: Windows-Engine, `tools/terrain_sichttest.ps1`, Wegwerf-Probekarte
(4096x4096 Elmo, temperiert), gleiche Kamera je Paar. Der Kampfl&auml;ufer im Bild
ist der Massstab.

| Bild | was |
|---|---|
| 01 | Birke aus dem Quaternius Ultimate Nature Pack, **roh** — die gelieferten Materialfarben |
| 02 | dieselbe Birke, **mit Conatus-Palette** (`bark_light`, `bark`, `leaf`, `leaf_shade`) |
| 03 | Busch aus dem Kenney Nature Kit, **roh** |
| 04 | derselbe Busch, **mit Conatus-Palette** (`leaf`) |
| 05 | Baum aus unserer eigenen Fabrik, gleiche Karte, gleicher Massstab (35,6 Elmo) |
| 06 | Fels aus unserer eigenen Fabrik, gleiche Karte |
| 07 | Birke mit Palette, ohne Massstabs-Einheit |

Poly Haven liefert kein Bild: das kleinste Naturmodell der ganzen Bibliothek hat
3319 Dreiecke (Deckel 2000) und es gibt dort kein OBJ — das Material kommt gar
nicht erst bis zur Karte.
