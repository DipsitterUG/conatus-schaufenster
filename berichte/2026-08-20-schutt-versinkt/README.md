# Schutt versinkt (Studio#445, Ansage cnc#117)

Fels-Schutt bleibt nicht mehr ewig liegen: nach 60 s Liegezeit sinkt er in
8 s sichtbar ab und wird geloescht. Ein Erntebefehl bricht das Sinken ab.

`versinken-fuenf-zeitpunkte.png` -- ein Windows-Lauf, eine Kamera, fuenf
Zeitpunkte. Die Sinkdauer ist der echte Spielwert (ca. 1,5 Elmo/s); nur die
Liegezeit ist fuer den Abzug von 60 s auf 5 s verkuerzt.

Abzug vom Abnahme-Helfer, Spiel-main `f02ffe7`.
