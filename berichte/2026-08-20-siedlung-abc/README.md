# Siedlung der Einheimischen -- A/B/C zur Wahl (Studio#424, fuer #415)

Blockouts, keine Fertigmodelle: beurteilt werden Silhouette, Masse und
Register. Textur, Feinbau und Pieces kommen erst nach der Wahl.

| Bild | Variante |
|---|---|
| `abc-bogen.png` | alle drei, drei Ansichten, gleicher Massstab |
| `siedlung-a-wellblechbaracke.png` | A -- langer flacher Riegel unter Pultdach |
| `siedlung-b-umzaeunter-hof.png` | B -- der Zaun ist der Bau, Huetten stehen darin |
| `siedlung-c-aufgestockt.png` | C -- Betonstumpf mit Blechaufbau, Wasserturm |

Alle drei fuellen dieselbe Grundflaeche (4 x 4 Bauquadrate = 64 x 64), damit
der Bogen Silhouetten vergleicht und nicht Grundrisse. Die Rauchballen sind
Platzhalter fuer einen Partikeleffekt und gehoeren nicht ins Modell.

Sichttest unter Windows steht aus.
